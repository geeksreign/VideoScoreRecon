# 隐私政策（Privacy Policy）

**ScoreStitch（Chrome 扩展，视频乐谱提取）**

最后更新：2026-11-04

## 我们不收集任何数据

本扩展的设计原则是**全部处理在您的设备本地完成**：

- **视频不离开本机**：视频流由您的浏览器直接从 B 站下载到内存中处理，不上传到任何第三方或开发者服务器。
- **不收集个人信息**：我们不收集、不存储、不传输您的浏览历史、账号信息、设备信息或任何个人数据。
- **Cookie 不上传**：如您在设置中填写 B 站 Cookie（SESSDATA），它仅保存在浏览器本地存储（`chrome.storage.local`），仅用于您本机向 B 站请求更高画质的视频流，绝不会发送给除 B 站之外的任何一方。
- **无跟踪、无分析**：不包含任何统计、分析、广告或跟踪代码。
- **无远程代码**：扩展运行的所有代码均随扩展一同安装，不从远程加载任何脚本。

## 本地可选功能（高级模式）

如您在设置中配置了本地 Python 服务地址（`http://127.0.0.1:8000`），扩展仅与**您自己电脑上**运行的该服务通信，数据同样不离开本机。

## 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 在本地保存您的设置（服务地址、Token、Cookie） |
| B 站域名访问 | 在视频页注入操作面板；获取视频流与视频信息 |
| 视频 CDN 域名访问 | 下载视频数据（仅视频，不涉及其它内容） |
| `127.0.0.1` | 仅当您启用高级本地服务模式时通信 |
