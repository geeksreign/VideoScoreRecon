# 隐私政策（Privacy Policy）

**ScoreStitch（Chrome 扩展，视频乐谱提取）**

最后更新：2026-11-11

## 我们不收集任何数据

本扩展的设计原则是**全部处理在您的设备本地完成**：

- **视频不离开本机**：视频流由您的浏览器直接从 B 站及其 CDN 下载到内存中处理，不上传到任何第三方或开发者服务器。
- **不收集个人信息**：我们不收集、不存储、不传输您的浏览历史、账号信息、设备信息或任何个人数据。
- **无 Cookie 存储**：不使用扩展自身的 Cookie 或登录凭据字段；访问视频流仅依赖您在 B 站页面当前的登录态，且默认使用无需登录的游客视图。
- **无跟踪、无分析**：不包含任何统计、分析、广告或跟踪代码。
- **无远程代码**：扩展运行的所有代码（含 OpenCV.js 检测引擎）均随扩展一同安装，不从远程加载任何脚本。

## 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 在浏览器本地保存您的设置（提取画质档位、抽帧间隔秒数），不上传 |
| `www.bilibili.com` / `api.bilibili.com` | 在 B 站视频页注入操作面板；请求视频页信息与视频流地址 |
| 视频 CDN 域名（bilivideo 等） | 直接下载视频数据（仅视频字节，不涉及其它内容） |
| `*://*/*`（可选，默认不授予） | 仅当常规下载源全部失败时，经您主动点击「授权全网访问」后，用于访问任意 CDN 域名兜底重试；平时不申请、不持有 |

## 用途说明

本扩展用于从 B 站滚动乐谱类视频中自动检测、裁剪乐谱区域，抽帧去重后拼接为完整乐谱长图，供个人学习参考。
